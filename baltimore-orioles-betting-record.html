Methodology

Results and closing lines come from the Bet Legend game database: final scores for every regular season game since 2016, with the closing moneyline, run line and total. Postseason games are excluded. Moneyline units risk 1 unit per game at the close, so a win at -150 pays +0.67u and a win at +130 pays +1.30u. The run line record compares the final margin with the closing line (MLB run lines are 1.5 runs, so there are no pushes). Over and under results compare total runs with the closing total; an exact match is a push. 2026 figures run through Sep 25, 2026.
